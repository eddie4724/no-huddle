# No Huddle

Retro pixel football: call your own plays, run a franchise, play on your phone.

**Play it: https://eddie4724.github.io/no-huddle/**

On a phone, use "Add to Home Screen" to play full screen. Turn the phone sideways.

## Online mode

`server/` holds the online game server (one prebuilt file) and `render.yaml` tells Render.com how to run it for free.
`online.json` tells the website where the server is.
